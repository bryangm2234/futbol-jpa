Un sistema completo de gestión de clubes de fútbol con Spring Boot y JPA.

Gestión de Clubes

Registra clubes con nombre, entrenador, asociación, jugadores y competiciones en un solo formulario.

Plantel Dinámico

Agrega jugadores al crear el club o edítalos después. Número de camiseta y posición incluidos.

Competiciones

Relación ManyToMany entre clubes y competiciones. Un club puede participar en varias ligas.

Asociaciones

Cada club pertenece a una federación o asociación deportiva con país y presidente.

Relaciones JPA
implementadas

El proyecto implementa las cuatro relaciones fundamentales de JPA entre entidades, con carga perezosa y eliminación en cascada.

@OneToOne Club → Entrenador
@OneToMany Club → Jugadores
@ManyToOne Club → Asociacion
@ManyToMany Club ↔ Competicion
@Entity
public class Club {
  @OneToOne(fetch = FetchType.LAZY)
  private Entrenador entrenador;

  @OneToMany(fetch = FetchType.LAZY)
  @JoinColumn(name = "id_club")
  private List<Jugador> jugadores;

  @ManyToOne(fetch = FetchType.LAZY)
  private Asociacion asociacion;

  @ManyToMany(fetch = FetchType.LAZY)
  private List<Competicion> competiciones;
}
